# OnlyOffice Vue Demo — 应用镜像安装说明（不含 Document Server）
# Document Server 按 docs/docker.txt（端口 19101）单独启动。

## 前置
1. 已安装 Docker
2. 已按 docs/docker.txt 启动 Document Server（-p 19101:80，JWT_SECRET 如下）
3. 浏览器、Document Server、本容器能互相访问下面配置的 URL

Document Server 参考：

  docker run -d \
    --name documentserver \
    -p 19101:80 \
    --restart always \
    -e JWT_ENABLED=true \
    -e JWT_SECRET=+keng2vx4V2ei1k/2wAsbxjpNP/v6Ew7uhyaJ9hgOr4= \
    -e JWT_HEADER=Authorization \
    -e CORS_ENABLED=true \
    -e CORS_ALLOWED_ORIGINS=* \
    onlyoffice/documentserver:latest

## 构建镜像

在项目根目录执行（默认使用阿里云 npm 源 https://registry.npmmirror.com）：

  docker build -t onlyoffice-vue-demo:latest .

如需官方源：

  docker build --build-arg NPM_REGISTRY=https://registry.npmjs.org/ -t onlyoffice-vue-demo:latest .

## 启动（用 -e 覆盖 .env 同名参数）

容器内固定监听 4000，对外用 -p 映射到 19102。

  docker rm -f onlyoffice-vue-demo 2>/dev/null || true

  docker run -d \
    --name onlyoffice-vue-demo \
    -p 19102:4000 \
    -e VITE_DOCUMENT_SERVER_URL=http://121.41.239.31:19101 \
    -e VITE_CALLBACK_BASE_URL=http://121.41.239.31:19102 \
    -e VITE_WS_BASE_URL=ws://121.41.239.31:19102 \
    -e VITE_ONLYOFFICE_JWT_SECRET=+keng2vx4V2ei1k/2wAsbxjpNP/v6Ew7uhyaJ9hgOr4= \
    -e VITE_DOCUMENT_PATH=/files/demo.docx \
    onlyoffice-vue-demo:latest

## 可覆盖的环境变量（与 .env 一致）

  VITE_DOCUMENT_SERVER_URL   Document Server 地址（浏览器可访问），默认 :19101
  VITE_CALLBACK_BASE_URL     本应用 HTTP 对外地址（浏览器与 Document Server 可访问），默认 :19102
  VITE_WS_BASE_URL           WebSocket 基址（不含 ?type=），默认 ws://主机:19102
  VITE_ONLYOFFICE_JWT_SECRET JWT 密钥（须与 Document Server JWT_SECRET 相同）
  VITE_DOCUMENT_PATH         演示文档路径，默认 /files/demo.docx

说明：前端通过 /config.js 在运行时读取上述变量，修改 -e 后重启容器即可生效，无需重新 build。
容器内端口固定 4000，对外端口只改 -p 左侧即可（同时改 VITE_CALLBACK_BASE_URL / VITE_WS_BASE_URL 中的端口）。

## 访问

  前端:   http://<主机IP>:19102/
  文档:   http://<主机IP>:19102/files/demo.docx
  回调:   http://<主机IP>:19102/onlyoffice/callback
  配置:   http://<主机IP>:19102/config.js
  DS:     http://<主机IP>:19101/

## 插件部署（jsapi-executor）

插件 WebSocket 地址来自 App 的 editorConfig.plugins.options（即 VITE_WS_BASE_URL）。
勿在社区版调用 createConnector/SetPluginsOptions，可能导致编辑器无法编辑。
更新插件代码后：

  ./scripts/oo.sh

或见 docs/docker.txt；完成后硬刷新浏览器。

控制台正常日志：

  [WebSocket] 使用配置连接: ws://121.41.239.31:19102?type=plugin (来自 plugins.options)

若文档能打开但无法编辑：检查浏览器访问 Document Server 协同 WS
（ws://主机:19101/.../doc/.../c/）是否被安全组拦截；协同通道不通时 OO 常会变成只读。

## 常用命令

  docker logs -f onlyoffice-vue-demo
  docker restart onlyoffice-vue-demo
  docker rm -f onlyoffice-vue-demo

## 一键脚本

  构建并启动应用，再部署插件:  ./scripts/install.sh
  仅部署插件到 Document Server:  ./scripts/oo.sh
